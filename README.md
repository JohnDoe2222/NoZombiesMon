# Jamaica · Family Travel Health Plan

Static page for GitHub Pages. Departure 29 Dec 2026.

## Files (all at the repository root)
- `index.html` — the page (self-contained: styles and script inline)
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Publish
1. Upload both files to the root of the repo (not a subfolder).
2. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
3. The link appears at the top of the Pages screen within a minute or two:
   `https://<username>.github.io/<repo-name>/`
